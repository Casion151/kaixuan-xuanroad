# Website fonts

## Chinese — 阿里妈妈刀隶体 (Alimama DaoLiTi)

The website's CSS family name `KaiXuan Lishu` is an alias for the original Alimama DaoLiTi Regular font. This is a clerical-script (隶书) variant with angular strokes inspired by the 爨宝子碑 inscription.

## English — Geist and Geist Mono

The website reuses its existing self-hosted Geist and Geist Mono font files under `_vinext_fonts/`. Shared face declarations in `site-fonts.css` make these English fonts available to the tutorial pages as well. Geist is a variable font, while Alimama DaoLiTi has one Regular (400) weight.
